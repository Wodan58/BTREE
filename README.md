BTREE
=====

Build|Linux
---|---
status|[![GitHub CI build status](https://github.com/Wodan58/BTREE/actions/workflows/cmake.yml/badge.svg)](https://github.com/Wodan58/BTREE/actions/workflows/cmake.yml)

BTREE is a simple implementation of the b-tree algorithm. Its purpose is to
demonstrate the workings of a b-tree.

Installation
------------

    cd build
    cmake -G "Unix Makefiles" ..
    cmake --build .
